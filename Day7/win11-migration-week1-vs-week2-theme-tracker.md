## New Theme in Week 2

### Excel Crashes on Large Files
**W2 Count:** 9 | **Severity:** Blocker  
**Not present in week 1**

Nine users — concentrated in the Finance team — report Excel crashing or freezing when opening large spreadsheets. One user identified files over 10MB as the trigger. Users are losing unsaved work on each crash.

**Representative comments:**
- *"Excel crash is really disruptive, losing unsaved work each time."* (ID 13)
- *"Excel crashing has become a real productivity problem for finance team."* (ID 20)
- *"New Excel crash issue -- happens specifically with files over 10MB."* (ID 33)
- *"Excel crash is new and quite disruptive, please prioritise."* (ID 37)

**Likely cause:** Possible Office 32-bit vs 64-bit mismatch post-migration, or a missing compatibility patch for the Win11 build. Needs investigation against Finance team machine configuration and Office version.
